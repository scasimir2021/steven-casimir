These four PNGs are design targets from the portfolio concept work. They are references, not runtime screenshots. The production site uses one shared data model and recreates the four orientations with responsive HTML/CSS/JS.

1. `01-cosmic.png` — cinematic / stars / gold.
2. `02-builder.png` — dense builder / engineering dashboard.
3. `03-operator.png` — green operator / Lawn-A-Mercy energy.
4. `04-dashboard.png` — high-density system dashboard.
